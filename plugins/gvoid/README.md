# GVOID plugin

Connects Claude to your GVOID account so it can generate images, video clips,
cinematic voices, songs, sound effects, 3D models and character animations for
you, and find or upload your own files to use as references. Every creation is
charged in voids from your balance and saved in your GVOID library.

Setup: create an API key in GVOID → Profile → API & MCP → New key, then install
the plugin. Claude Code asks for the key once and stores it in your system's
secure store; it is sent to `https://gvoidstudio.com/mcp` as a bearer token and
nowhere else.
